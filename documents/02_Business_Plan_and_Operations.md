# 📘 خطة العمل، الدراسة التقنية، واستراتيجية التشغيل — مشروع «خُضرة»

> **الوثيقة رقم 02** ضمن ملف الاحتضان والتمويل (`Technopark Fès` / `Tamwilcom` / `INDH`).
> تجمع هذه الوثيقة: **الدراسة التقنية للمنصة (MVP) + خطة التموين والتوصيل بفاس + مؤشرات الأداء (KPIs) + إدارة المخاطر**.

---

## 1. الدراسة التقنية للمنصة الرقمية (Étude Technique & Produit MVP)

تم تطوير وبناء منصة **«خُضرة»** الرقمية بالكامل وفق أحدث معايير هندسة البرمجيات، مما **يُزيل أي مخاطرة تقنية** أمام لجان الاستثمار ويضمن جاهزية فورية للتشغيل الفعلي.

### أ) البنية المعمارية (Tech Stack)

| المكوّن | التقنية المعتمدة | القيمة المضافة للمشروع |
| :--- | :--- | :--- |
| **الواجهة الأمامية** | `React 19` + `TypeScript` + `Tailwind CSS` | أداء فائق، بنية برمجية آمنة، وسرعة تحميل `< 2 ثانية` على شبكات `4G` |
| **تطبيق الجوال** | **PWA (Progressive Web App)** | تثبيت فوري على هواتف `Android` و `iOS` بضغطة زر دون استهلاك ذاكرة الجهاز |
| **قاعدة البيانات والمزامنة** | `Supabase (PostgreSQL)` + `Realtime` | مزامنة لحظية للطلبات والتقييمات بين العميل ولوحة الإدارة مع نظام `Fallback` محلي |
| **الاستضافة السحابية** | `Cloudflare Pages / Vercel` | شبكة توصيل محتوى عالمية (`CDN`) بتكلفة استضافة تشغيلية `~0 د.م/شهر` |

### ب) منظومة الأمن السيبراني وحماية الطلبات (6 طبقات حماية)

| الطبقة | التقنية المعتمدة | الهدف التشغيلي |
| :---: | :--- | :--- |
| **1** | **Cloudflare Turnstile** | حظر الروبوتات والطلبات الوهمية الآلية (`Anti-Bot`) |
| **2** | **Rate Limiting** | سقف أمان (3 طلبات كحد أقصى في الساعة لكل مستخدم) |
| **3** | **Cooldown System** | فترة تهدئة ذكية بين الطلبات المتتالية لمنع الإرسال العشوائي |
| **4** | **Idempotency Keys** | منع تكرار تسجيل نفس الطلب عند ضعف الإنترنت لدى الزبون |
| **5** | **Input Sanitization** | تطهير المدخلات برمجياً ضد هجمات `XSS` و `SQL Injection` |
| **6** | **SHA-256 Admin PIN + RLS** | تشفير الدخول للوحة الإدارة مع سياسات أمان قواعد البيانات (`Row-Level Security`) |

### ج) الوحدات الوظيفية المبتكرة (Core Functional Modules)
1. **محرك الأوزان الذكي (`Smart Weight Engine`):** يتيح للزبون اختيار الكميات بالكيلوغرام بدقة (`0.5 كغ، 1 كغ، 1.5 كغ...`) أو بالوحدة مع حساب لحظي للسعر الإجمالي وشريط التوصيل المجاني.
2. **صناديق العائلة الأسبوعية (`Family Boxes`):** باقات مسبقة الإعداد ترفع متوسط قيمة السلة (`AOV`) بنسبة **40% إلى 60%**.
3. **نظام التوصيل الجغرافي التفاعلي (`Interactive Geo-Delivery`):**
   * خريطة تفاعلية (`Leaflet + OpenStreetMap`) تعرض مركز التوزيع بطريق إيموزار، **نطاق التوصيل السريع (4.5 كم — 30 دقيقة)**، و**نطاق التوصيل الشامل (8.5 كم — 60 دقيقة)**.
   * التقاط إحداثيات `GPS` تلقائياً من هاتف العميل والتحقق الآلي من وقوع العنوان داخل مدينة فاس، مما يقلل أخطاء التسليم بنسبة **90%**.
4. **تعدد وسائل الدفع وتوثيق التحويلات (`Multi-Payment System`):**
   * الدفع نقداً عند الاستلام (`COD`) أو عبر التحويل البنكي لـ **6 بنوك ومؤسسات وطنية** (`CIH, Attijariwafa, Populaire, BMCE, Barid Bank, Cash Plus`) مع إرفاق صورة وصل التحويل مباشرة في الطلب.
5. **نظام الإدارة واللوحة المالية المتكامل (`Admin & Finance Mini-ERP`):**
   * **لوحة العمليات:** متابعة فورية لحالات الطلبات (`قيد الانتظار` ← `قيد التجهيز` ← `تم التوصيل`) مع تنبيهات صوتية للطلبات الجديدة وبحث وفلترة ذكية.
   * **طباعة بوليصة الشحن الحرارية (`Bordereau 80mm`):** ملصق شحن جاهز للطباعة يتضمن رقم الطلب، بيانات الزبون، تفاصيل السلة، مبلغ التحصيل `COD`، وإرشادات التوضيب في الصناديق العازلة.
   * **اللوحة المالية التحليلية:** تتبع مؤشرات الأداء (`الإيرادات، صافي الربح، عدد الطلبات، متوسط السلة`)، محاكاة توقعات 12 شهراً ونقطة التعادل، وتصدير التقارير بصيغة `CSV`.

### د) الميزة التنافسية التقنية مقارنة بالحلول التقليدية

| المعيار التقني | المتاجر التقليدية (Shopify / WooCommerce) | منصة «خُضرة» المخصصة |
| :--- | :---: | :---: |
| **تطبيق جوال فوري (PWA)** | يتطلب اشتراكاً إضافياً مكلفاً | **مُدمج مجاناً** |
| **خريطة تغطية فاس + تحقق GPS** | غير متوفر افتراضياً | **مُدمج بالكامل** |
| **لوحة مالية + طباعة Bordereau 80mm** | يتطلب إضافات مدفوعة | **مُدمج بالكامل** |
| **حماية ضد الطلبات الوهمية (5+ طبقات)** | محدود | **متكامل (Turnstile + Rate Limit)** |
| **التكلفة الشهرية الثابتة للبرمجيات** | 300 إلى 1,500 د.م / شهر | **~0 د.م / شهر** |

## 2. الخطة التشغيلية واللوجستية بمدينة فاس (Operations & Logistics)

### أ) الدورة التشغيلية اليومية (Daily Workflow)
| التوقيت | المرحلة التشغيلية | التفاصيل والإجراءات المعيارية (SOP) |
| :---: | :--- | :--- |
| **05:30 – 07:30** | **التموين الصباحي المباشر** | شراء الخضر والفواكه الطازجة من سوق الجملة بنسودة والضيعات الفلاحية المجاورة بناءً على الطلبات المسجلة وتوقعات اليوم. |
| **07:30 – 09:00** | **الفرز، التوزين، والتوضيب** | فرز الحبات السليمة، الوزن الإلكتروني الدقيق، التعبئة في أكياس مهوّاة وصناديق حافظة للبرودة (`Cooler Boxes`)، وإلصاق الـ `Bordereau`. |
| **09:00 – 13:00** | **الجولة الصباحية للتوصيل** | انطلاق مسارات التوصيل المجمّعة (`Batching`) لتغطية طلبات الصباح وتوريدات الـ `B2B` (المقاهي والمطاعم). |
| **16:00 – 20:30** | **الجولة المسائية والتسوية** | توصيل طلبات المساء للعائلات والموظفين، تليها التسوية اليومية لمبالغ التحصيل النقدي (`COD`) في اللوحة المالية. |

### ب) تقسيم مدينة فاس إلى 4 قطاعات ذكية لتجميع المسارات (Route Batching)
لتخفيض تكلفة التوصيل من `20–25 درهم` (للتوصيل الفردي) إلى **`8–10 دراهم فقط للطلب`**، يتم تجميع كل 3 إلى 4 طلبات متجاورة في جولة واحدة حسب القطاعات الأربعة:
1. **القطاع الأوسط والجنوبي القريب (نطاق 4.5 كم - توصيل في 30 دقيقة):** طريق إيموزار، الأطلس، أكدال، فلورنس، النرجس، سايس، مونفلوري.
2. **القطاع الغربي:** واد فاس، المسيرة، بنسودة، زواغة، عين السمن.
3. **القطاع الشمالي:** مرجة، عين قادوس، بن دباب، حي طارق.
4. **القطاع الشرقي والتاريخي:** طريق صفرو، حي الزهور، البطحاء، باب بوجلود.

### ج) معايير حفظ الجودة في صناديق التوصيل العازلة (50L Cooler Box)
* **الطبقة السفلى:** الخضروات الثقيلة والصلبة (بطاطس، بصل، جزر، قرع).
* **الطبقة الوسطى:** الخضروات الورقية والأعشاب في أكياس مهوّاة (نعناع، معدنوس، خس، سبانخ).
* **الطبقة العليا:** الفواكه الحساسة والطماطم والبيض لمنع أي ضغط أو تلف أثناء النقل.

## 4. مصفوفة تقييم المخاطر وخطط التخفيف (Risk Management)

| المخاطرة المحتملة | درجة الأثر | خطة الوقاية والتخفيف المعتمدة في «خُضرة» |
| :--- | :---: | :--- |
| **تلف أو ذبول المنتجات الطازجة (Perishability)** | متوسطة | التموين اليومي حسب الطلب (Just-in-Time)، استخدام خزائن وصناديق مبردة، وتصريف الفائض عبر عروض الصناديق اليومية. |
| **ارتفاع تكلفة التوصيل للطلبات المتفرقة** | عالية | تطبيق نظام تجميع المسارات (`3-4 طلبات/جولة`)، واعتماد حد أدنى للطلب مع شريط تحفيزي للتوصيل المجاني. |
| **الطلبات الوهمية أو إلغاء الطلب عند الوصول** | متوسطة | تفعيل حماية `Cloudflare Turnstile` + التحقق من رقم الهاتف عبر واتساب + إمكانية الدفع المسبق بالتحويل البنكي. |
| **تقلب أسعار سوق الجملة موسمياً** | متوسطة | تحديث فوري ومرن للأسعار من لوحة التحكم، والتركيز على الفئات ذات الهامش المستقر (الفواكه، البقالة، وصناديق العائلة). |

## 5. الإطار القانوني والمؤسسي للمشروع (الصيغة المعتمدة: شركة SARL)

تم اختيار الصيغة القانونية **شركة ذات مسؤولية محدودة (`SARL` / `SARL AU`)** بدل نظام المقاول الذاتي للأسباب الاستراتيجية والقانونية التالية:
1. **إبرام عقود العمل القانونية (السائقون والموظفون):** تمنح شركة `SARL` الأهلية القانونية لتشغيل السائقين ومساعدي الفرز والتوضيب بعقود عمل رسمية والتصريح بهم لدى الصندوق الوطني للضمان الاجتماعي (`CNSS`)، وهو ما لا يسمح به نظام المقاول الذاتي.
2. **التعاقد التجاري مع المؤسسات (`B2B`) والفوترة الرسمية:** تتيح صيغة `SARL` التعاقد مع الفنادق، المطاعم، والمقاهي بمدينة فاس وإصدار فواتير ضريبية رسمية (`ICE / IF / RC`) دون التقيد بالسقف السنوي المحدود للمقاول الذاتي.
3. **الأهلية الكاملة لصناديق التمويل والاحتضان:** تشترط برامج **Technopark** وصندوق **Innov Invest (Tamwilcom)** أن يكون المشروع مهيأً في إطار شركة تجارية (`SARL`) قابلة للنمو وتوسيع رأس المال.
4. **فصل الذمة المالية وقابلية دخول المستثمرين:** تحمي صيغة `SARL` الذمة المالية الشخصية للمؤسس وتسمح مستقبلاً بدخول شركاء أو صناديق استثمار عبر الحصص الاجتماعية (`Parts Sociales`).
