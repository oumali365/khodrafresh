# دليل صور صناديق العائلة (Family Boxes)

ضع الصور بصيغة **`.webp`** بالأسماء التالية في هذا المجلد (`public/images/family-boxes/`):

1. **`family-small.webp`** -> صندوق عائلة صغيرة (2-3 أفراد)
2. **`family-medium.webp`** -> صندوق عائلة متوسطة (4-5 أفراد)
3. **`family-large.webp`** -> صندوق عائلة كبيرة (6-8 أفراد)

بمجرد وضع الصور بهذه الأسماء، ستظهر تلقائياً في المتجر وفي النافذة المنبثقة للتفاصيل.
إذا لم تكن الصورة موجودة، سيعرض المتجر تلقائياً بطاقة بديلة أنيقة بدون أي خطأ.
