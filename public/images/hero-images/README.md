# دليل صور الواجهة الرئيسية (Hero Images)

ضع صور الواجهة الرئيسية في هذا المجلد (`public/images/hero-images/`) بالأسماء التالية:

1. **`hero-1.webp`** (أو `hero-1.jpg`) -> بطاقة الهيرو الأولى (خضار وفواكه طازجة مباشرة لباب دارك)
2. **`hero-2.webp`** (أو `hero-2.jpg`) -> بطاقة الهيرو الثانية (صناديق عائلة خُضرة)

بمجرد وضع الصور بهذه الأسماء، ستظهر تلقائياً في بطاقات الواجهة الرئيسية (Hero).
