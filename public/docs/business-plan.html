خطة العمل والدراسة التقنية — شركة خُضرة (SARL)

بنية برمجية متكاملة (PWA + Cloud ERP + GPS) واستراتيجية التوزيع السريع بمدينة فاس

1. البنية المعمارية للمنصة الرقمية (Tech Stack & Product MVP)

المكوّن التقني التقنية المعتمدة القيمة المضافة للمشروع
الواجهة الأمامية React 19 + TypeScript + Tailwind CSS أداء فائق، بنية برمجية آمنة، وسرعة تحميل أقل من ثانيتين على شبكات الجيل الرابع.
تطبيق الجوال الفوري PWA (Progressive Web App) تثبيت فوري على شاشات هواتف Android و iOS بضغطة زر دون استهلاك ذاكرة الهاتف.
قاعدة البيانات والمزامنة Supabase (PostgreSQL) + Realtime مزامنة لحظية للطلبات والتقييمات مع نظام Fallback محلي لضمان استمرارية العمل.
الاستضافة وشبكة التوزيع Cloudflare Pages / Vercel CDN استضافة سحابية فائقة السرعة بتكلفة تشغيلية ثابتة ~0 د.م/شهر.

2. منظومة الأمن السيبراني وحماية الطلبات (6 طبقات حماية)

الطبقة التقنية المعتمدة الهدف التشغيلي
1Cloudflare Turnstileحظر الروبوتات والطلبات الوهمية الآلية (Anti-Bot).
2Rate Limitingسقف أمان (3 طلبات كحد أقصى في الساعة لكل مستخدم).
3Cooldown Systemفترة تهدئة ذكية بين الطلبات المتتالية لمنع الإرسال العشوائي.
4Idempotency Keysمنع تكرار تسجيل نفس الطلب عند ضعف الإنترنت لدى الزبون.
5Input Sanitizationتطهير المدخلات برمجياً ضد هجمات XSS و SQL Injection.
6SHA-256 Admin PIN + RLSتشفير الدخول للوحة الإدارة مع سياسات أمان قواعد البيانات (Row-Level Security).

3. الوحدات الوظيفية المبتكرة والميزة التنافسية

  • محرك الأوزان الذكي (Smart Weight Engine): اختيار الكميات بالكيلوغرام بدقة داخل السلة مع حساب لحظي للسعر وشريط التوصيل المجاني.
  • صناديق العائلة الأسبوعية: باقات مسبقة الإعداد ترفع متوسط قيمة السلة (AOV) بنسبة 40% إلى 60%.
  • التوصيل الجغرافي التفاعلي (Leaflet + GPS): خريطة تفاعلية تعرض مركز التوزيع بطريق إيموزار ونطاق التوصيل السريع (4.5 كم) والشامل (8.5 كم) مع التقاط إحداثيات العميل آلياً.
  • تعدد وسائل الدفع: الدفع نقداً عند الاستلام (COD) أو التحويل البنكي لـ 6 بنوك ومؤسسات وطنية مع إرفاق صورة الوصل مباشرة.
  • نظام الإدارة واللوحة المالية (Mini-ERP): متابعة الطلبات بتحديث صوتي، طباعة ملصق الشحن الحراري Bordereau 80mm، واللوحة المالية مع تصدير CSV.

6. الإطار القانوني والمؤسسي للمشروع (الصيغة المعتمدة: شركة SARL)

  • إبرام عقود العمل القانونية (CNSS): تمنح صيغة SARL الأهلية القانونية لتشغيل السائقين ومساعدي الفرز والتوضيب بعقود عمل رسمية، وهو ما لا يتيحه نظام المقاول الذاتي.
  • التعاقد التجاري مع المؤسسات (B2B) والفوترة الضريبية: القدرة على التعاقد مع الفنادق، المطاعم، والمقاهي بفاس وإصدار فواتير رسمية (ICE / RC) دون السقف السنوي المحدود للمقاول الذاتي.
  • الأهلية الكاملة لصناديق التمويل والاحتضان: مطابقة تامة لشروط Technopark Fès وصندوق Innov Invest (Tamwilcom) وINDH.
  • فصل الذمة المالية وقابلية دخول المستثمرين: حماية الذمة المالية الشخصية للمؤسس وإمكانية فتح رأس المال للشركاء عبر الحصص الاجتماعية (Parts Sociales).
